## 一、人性是什么：把"贪婪好色"讲透
> 事业要顺着人性。什么是人性？人性就是贪婪、好色。
这句话点的是人性最底层的两个驱动力，但商业上顺着的人性更全，可归纳为**六大驱动**：
| 人性 | 白话 | 商业应用 |
|------|------|---------|
| **贪婪** | 想得到更多、想占便宜 | 促销、低价、会员返利、"暴富梦" |
| **好色 / 爱美** | 对美、颜值、欲望的向往 | 美业、颜值经济、约会社交、审美消费 |
| **懒惰** | 不想动手、想省事 | 便利店、外卖、代劳服务、即时满足 |
| **虚荣** | 想被认可、攀比 | 奢侈品、社交货币、晒与炫耀 |
| **恐惧** | 怕失去、怕老、怕病 | 保险、保健品、医疗、养生 |
| **好奇** | 猎奇、追求新鲜 | 新奇特产品、造节噱头、盲盒 |
**本质**：人不是理性的，人是被欲望驱动的。所有能起量、能持续被消费的生意，几乎都在"顺着"这些底层欲望中的某一个或某几个。
## 二、自己的洞察，全都装进这张表
回头看我沉淀过的判断，几乎都能落到这六大人性里：
**这说明什么**：我不是在做"判断行业"，而是在反复验证同一件事——**能做大、能赚钱的生意，底层都是"顺人性的"**。看懂一个人性，就多看懂一类生意。
## 三、顺人性的案例库
把"顺人性"落到具体案例，分两类：**正面顺着人性真实满足**，和**反面利用人性踩线收割**。
### 正面案例：顺着人性，真实满足
| 案例 | 顺着的人性 | 怎么顺着 | 佐证数据 |
|------|-----------|---------|---------|
| **拼多多** | 贪婪（占便宜） | 拼团 + 极致低价，重塑"质价比" | "用惯拼多多发现很多东西不该这么贵"成热议；段永平、李录等价值派重仓 |
| **泡泡玛特** | 好奇 + 虚荣 + 情绪 | 盲盒的"抽"刺激猎奇，IP 做"情绪治愈、情感投射"，买的是情感认同而非实物 | THE MONSTERS 系列收入同比增 **668%**、毛绒品类增 **1276%**，市值一度破 4200 亿港元 |
| **蜜雪冰城** | 贪婪（便宜）+ 懒惰 | 极致低价 + 密集门店随取随走 | 6 万店，下沉市场心智 |
| **7-Eleven / 便利店** | 懒惰（即时满足） | 开在"最后一公里"，随时买到 | 全球万店，24 小时即时零售 |
| **外卖（美团等）** | 懒惰（不想出门） | 送到家 | 即时配送万亿市场 |
| **医美 / 美业** | 爱美 + 虚荣 | 变美 + 被夸 | 颜值经济持续扩张 |
| **保险 / 保健品 / 中医治未病** | 恐惧（怕老怕病） | 给安全感、养生防病 | 万亿级市场 |
### 反面案例：利用人性踩线（红线警示）
| 案例 | 利用的人性 | 怎么踩线 | 后果 |
|------|-----------|---------|------|
| **手游抽卡** | 贪婪 + 侥幸 | 保底/概率陷阱，诱导氪金 | 原神单角色满命成本超 2000 元；美国 FTC 因概率不透明开出 **2000 万美元**罚单 |
| **乙女游戏 / 直播打赏** | 情感 + 虚荣 | 虚拟情感陪伴、诱导消费 | 未成年人 3 个月充值 7000 多元，年龄门槛形同虚设，引监管关注 |
| **卖课"月入十万"** | 贪婪 + 焦虑 | 画饼割韭菜 | 虚假承诺，口碑反噬 |
| **美业"假装说有用"** | 爱美 + 虚荣 | 虚假宣传 | 监管处罚（虚假宣传红线） |
### 小生意案例：普通人也能顺着人性（更贴近实战）
大案例验证逻辑，但离普通人太远。真正有参考价值的是**身边的小生意**——顺人性不看你做多大，而看**用最小动作顺哪种人性**。用"人性 → 最小动作 → 为什么赚"拆解：
| 小生意 | 顺的人性 | 最小动作 | 为什么赚 |
|--------|---------|---------|---------|
| **小区早餐摊** | 懒 + 便宜 | 开在必经路口、出摊早 | 不想自己做早餐的人随手买 |
| **十元店 / 杂货铺** | 贪 + 好奇 | 低价走量、品种多 | 淘货的快感 |
| **理发店低价引流** | 贪 + 懒 | 首次低价，办卡锁定 | 复购会员 |
| **药店免费测血压** | 恐惧 + 占便宜 | 免费检测引流 | 推销保健品 / 药 |
| **菜市场试吃 / 多送葱** | 贪 | 让你觉得占便宜 | 促成购买 + 回头 |
| **社区团购团长** | 懒 + 贪 | 拼团、送上门 | 抽佣 |
| **儿童摇摇车** | 好奇 + 虚荣 | 孩子要、家长掏 | 小成本高毛利 |
| **算命 / 转运物品** | 恐惧 + 好奇 | 给"确定性" | 为情绪买单 |
| **旅馆样板间（你的一手）** | 贪 + 好奇 | 只改两间房 + 拍照上传 | 花一分钱享受一块钱 |
**关键**：小生意不用做大，但道理和大生意一模一样——**找一个"最小动作"去顺某一种人性，先跑通一个能赚钱的小闭环**。这就是你旅馆样板间验证过的：改造两间房（最小动作），顺"贪便宜 + 好奇"，当天就有客流、两个样板间也照样入住。
**结论**：同一个"人性"，正面顺着是"真实满足需求"，反面利用是"收割人性脆弱"。**分界线就一条——有没有真实交付。**
## 四、需求端 + 供给端：两条腿
> **需求端顺人性（有人想要）+ 供给端可复制（能做大）= 大生意**
"做大逻辑"（可复制、快速复制、供应链）管的是**供给端**——怎么把生意做大规模；
"顺着人性"管的是**需求端**——凭什么一直有人要。
| 组合 | 结果 |
|------|------|
| 顺人性 + 可快速复制 | **大生意**（蜜雪冰城：戳中"贪便宜" + 快速复制；7-Eleven：戳中"懒" + 快速复制） |
| 顺人性 + 不可复制 | 小生意（单店赚钱，做不大） |
| 可复制 + 不顺人性 | 有规模但没人持续要（昙花一现） |
| 都不占 | 做不起来 |
**一句话**：先问"有没有人想要"（顺不顺人性），再问"能不能做大"（能不能快速复制）。
## 五、红线：顺人性 ≠ 骗人性
顺着人性是"懂需求"，不是"利用人性的脆弱去骗"：
区别只在一件事：**有没有真实交付**。
- 有真实交付，顺人性就是好生意；
- 没有真实交付，顺人性就成了割韭菜——这正是我反复强调的红线：**真实与信任，不可靠虚假**。虚假能骗一时，骗不出复购和长期品牌。
## 六、检验清单：一个生意顺不顺人性
拿到一个生意，用这套问：
1. **它顺着哪种人性？**（贪/美/懒/虚荣/恐惧/好奇——至少说得出一个）
2. **是"真实满足"还是"虚假利用"？**（有真实交付吗？能复购吗？）
3. **需求端成立吗？**（有人持续想要，不是一次性冲动）
4. **结合供给端：能快速复制吗？**（有人要 + 能做大 = 大生意）
> 需求端问"人性"，供给端问"复制"。两端都过关，才配叫"能做大"的生意。
